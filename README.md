# Simple Sales Dashboard

A simple and interactive Sales Dashboard built with [Streamlit](https://streamlit.io/), [Pandas](https://pandas.pydata.org/), and synthetic data.

## Features

- **Synthetic Data Generation**: Automatically generates realistic mock sales records with randomized dates, categories, regions, units, and prices.
- **Interactive Filters**: Filter records by Region and Product Category from the sidebar.
- **Key Metrics (KPIs)**: Total Revenue, Units Sold, Total Orders, and Average Order Value.
- **Visualizations**:
  - Daily Sales Trend line chart
  - Sales by Category bar chart
  - Regional Sales Breakdown bar chart
- **Data Table**: Tabular view of recent sales orders.

## Getting Started

1. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the Streamlit app**:
   ```bash
   streamlit run app.py
   ```
